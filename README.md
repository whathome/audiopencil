# Audio Pencil

Talk instead of type. Private, on-device dictation and notes for Mac, iPhone and iPad.

- **Mac:** double-tap Fn, speak, then tap Fn to paste. Hold Fn for a raw transcript.
- **iPhone and iPad:** record a thought, walk or meeting; turn it into a note or copy the text.
- **Your files:** Markdown in Obsidian, a local/iCloud folder, Nextcloud or WebDAV.

No cloud AI. Interface in English, French and Spanish.

**Get started:** [Build and setup](docs/reference.md#build-and-run) (Xcode required). [Using another Xcode account?](docs/reference.md#using-another-xcode-account)

Mac video-call capture is a Debug-only preview.
